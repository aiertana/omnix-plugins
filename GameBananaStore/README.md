# GameBanana 在线商店

GameBanana mod 浏览/搜索/下载/安装插件。

> **源码与主仓库**：[aiertana/OMniX-GameBanana](https://github.com/aiertana/OMniX-GameBanana)
> （独立仓库，CI 自动出 Release，本目录是离线包镜像）

## 功能

- GameBanana 鸣潮 mod 浏览（最新发布/最多下载/最多点赞排序）
- 角色分类筛选（pill 行 + 弹出面板，带数量/图标）
- 下载窗口：自动识别角色（网页分类 → 角色库匹配，含禁用角色兜底）、安装目标记忆、全局下载进度
- 内置代理设置（不用/跟随系统/手动，带连接测试）

## 下载

[GameBananaStore_离线包.zip](./GameBananaStore_离线包.zip)

## 安装

OMniX → 功能专区 → 导入离线包；或解压到 `GamesData\Plugins\GameBananaStore\`。
